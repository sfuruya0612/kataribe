# 録音中のデバイス消失と権限拒否を処理する

Created: 2026-10-29
Model: DeepSeek V4.1 Flash 1017
優先度: P0
対応 ADR: ADR-0002 (docs/adr/0002-web-audio-recording-and-chunks.md)、ADR-0003 (docs/adr/0003-system-audio-virtual-device.md)、ADR-0012 (docs/adr/0012-menu-bar-and-main-window.md)
関連 PRD: R-2、R-3、非機能要件の録音の信頼性と権限
依存: 0010、0011

## 背景

ADR-0002 の未決事項は、録音中の入力デバイス変更を許可するか決めていない。
ADR-0003 は、録音中に BlackHole 2ch が見つからなくなった場合は録音を停止し、マイクだけの録音に自動で切り替えないとしている。
issue 0002 は、無音が続いてもマイクだけに自動で切り替えず、入力ソースは録音中に変更しないとしている。
デバイス消失と権限拒否を扱う issue がなく、挙動が実装者に委ねられている。

## 目的

BlackHole の消失、USB マイクの抜去、マイク権限の拒否を検出し、録音を守りながら利用者に案内する。
デバイス消失時の挙動を ADR と issue で一致させる。

## 方針

- 録音中に BlackHole 2ch が消失した場合は、録音を停止してチャンクを保存する。
  マイクだけの継続は、自動でも明示操作でも行わない。
- 録音中にマイクが消失した場合は、マイクトラックだけを停止し、システム音声の録音を続ける。
  マイクだけを選んでいた場合は録音を停止する。
  これは利用者による入力ソースの変更ではなく、デバイス消失時の例外とする。
- 録音開始時に選んだ入力デバイスを開けない場合は、その入力を無効にし、権限または接続の案内を出す。
  別の入力へ自動で切り替えない。
- デバイスの消失と権限の拒否は `meta.json` に記録する。

## やること

- `devicechange` と各トラックの `ended` を監視し、マイクと BlackHole の消失を検出する。
- BlackHole の消失時は、録音を停止し、書きかけのチャンクを保存し、エラーを表示する。
- マイクの消失時は、マイクトラックを停止し、システム音声の録音を続け、警告を表示する。
- マイク権限が拒否された場合は、入力デバイスの検出とマイク録音を無効にし、システム設定の該当箇所を開ける案内を出す。
- 録音開始時に BlackHole が見つからない場合は、issue 0001 に従ってシステム音声の選択肢を無効にし、README のセットアップ手順を案内する。
- デバイスの消失と権限の拒否を `meta.json` に記録する。
- 次のケースをテストする。
  - 録音中に USB マイクを抜く。
  - 録音中に BlackHole 2ch を消す。
  - マイク権限を拒否した状態で録音を開始する。
  - 録音中に音声出力を Multi-Output Device から外す。

## 完了条件

- 録音中に USB マイクを抜くと、5 秒以内に警告が出て、システム音声の録音が続く。
- 録音中に BlackHole 2ch を消すと、録音が停止し、チャンクが保存され、エラーが出る。
- マイク権限を拒否した状態では、マイクを使う録音を開始できず、システム設定への案内が出る。
- 別の入力へ自動で切り替わらない。
- `meta.json` にデバイス消失と権限拒否の時刻と種類が残る。
- 録音中に音声出力を外した場合は、issue 0002 の無音検出と矛盾しない。
