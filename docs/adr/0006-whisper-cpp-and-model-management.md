# ADR-0006: 文字起こしは whisper.cpp をローカル実行し、モデルはアプリから取得して Application Support に置く

Created: 2026-10-28
Model: DeepSeek V4.1 Flash 1017
Status: Accepted

## 背景

Kataribe は、録音停止後に自動で文字起こしを開始する（PRD の T-1）。
文字起こしは端末内で完結し、ネットワークがなくても動く必要がある（PRD の「非機能要件」）。
対応する言語は日本語と英語を中心とし、多言語が混在する会議では言語を自動判定する（PRD の T-7）。
Apple Silicon では 60 分の音声を 10 分以内に処理し、モデルは large-v3-turbo を標準とする（PRD の「非機能要件」）。

whisper.cpp は ggml 形式のモデルを子プロセスで実行でき、Metal と Core ML に対応する。
モデルを設定画面で選び、アプリ内からダウンロードできる（PRD の T-2）。
モデルをアプリに同梱すると、large-v3-turbo だけで約 1.6 GB になり、PRD のアプリ本体 300 MB 以下という目標を満たせない。
モデルは初回起動時か設定画面で別途ダウンロードし、アプリの外に置く必要がある。

文字起こしの精度は、モデルの大きさ、音声の品質、用語集の initial prompt に依存する。
Intel Mac は動作保証外とする。

## 決定

- 文字起こしには whisper.cpp を使い、メインプロセスから子プロセスとして起動する（ADR-0004）。
  Apple Silicon では Metal を有効にしたビルドを使う。
  Core ML は、対応するモデルと変換済みの成果物を用意できる場合に有効にする。
  Intel Mac は動作保証外とする。
- 既定のモデルは `ggml-large-v3-turbo` とする。
  設定画面で small、medium、large-v3-turbo から選べるようにする。
- モデルは `~/Library/Application Support/Kataribe/models/` に保存する。
  アプリのバンドルには含めない。
  設定画面にモデルごとのファイルサイズとディスク使用量を表示し、削除できるようにする。
- 初回起動時に既定モデルのダウンロードを案内する。
  サイズ、保存先、通信量を示し、利用者が開始または中止できるようにする。
- モデルはアプリ内から HTTPS でダウンロードする。
  ダウンロードの進捗、キャンセル、失敗時の再試行を画面に出す。
  ダウンロードは `.part` ファイルに書き、HTTP Range で再開する。
  SHA-256 のチェックサムを照合してから、モデルのファイル名に rename する。
  ダウンロードの前に、モデルのサイズと一時領域に必要な空き容量を確認する。
- モデルのダウンロード元、ファイル名、チェックサムはアプリの設定コードに固定し、ユーザーが任意の URL を指定する機能は MVP では持たない。
- 言語は自動判定を既定とし、日本語をヒントとして渡す。
  会議ごとに言語を固定する設定は MVP では持たない。
  文字起こしの結果は、話された言語のまま残す。
- 日本語の専門用語の精度を上げるため、initial prompt に渡す用語集を設定できるようにする。
  用語集はアプリ全体の設定として保存し、言語判定の結果が日本語のときだけ渡す。
- 無音や雑音に対する幻覚を抑えるため、`--no-speech-thold` と `--suppress-nst` を設定する。
  必要なら VAD を別途入れ、発話区間だけを文字起こしする。
- whisper.cpp の出力は、セグメントごとの開始時刻、終了時刻、テキストを含む形式で受け取る。
  メインプロセスがそれを `transcript.md` の形式に変換する（ADR-0011）。
- 文字起こしの完了判定、タイムアウト、再開は ADR-0007 で扱う。
  この ADR では、モデルの選択、ダウンロード、保存、言語、用語集を決める。
- 話者分離は MVP では行わない。
  話者分離を入れる場合は、別のモデルか後処理が必要になるため、次フェーズで ADR を起こす。
- whisper.cpp の版は固定し、モデルの形式と進捗解析の契約をその版に合わせる。
  版を上げるときは、モデルの互換性と文字起こしの品質を確認する。
- whisper.cpp とモデルのライセンス、著作権表示をアプリに同梱する。
  モデルの再配布条件がある場合は、ダウンロード元の条件に従う。

## 検討した選択肢

| 選択肢 | 採用しない理由 |
| --- | --- |
| macOS の Speech フレームワーク | 端末内で動き、モデルのダウンロードも不要だが、用語集の制御、タイムスタンプの形式、モデルの選択肢が whisper.cpp より狭い。PRD は whisper.cpp を指定している |
| WhisperKit などの Swift 実装 | Apple Silicon に最適化されているが、Swift のヘルパーを同梱する必要があり、Electron の構成から外れる。将来の ADR で検討する余地はある |
| MLX を使った Whisper | Apple Silicon では速いが、Python か Swift のランタイムが必要になる。配布と署名の構成が複雑になる |
| faster-whisper などの Python 実装 | Python のランタイムと依存を同梱する必要があり、アプリのサイズと起動時間が増える |
| クラウドの文字起こし API | 音声を端末外に送らないというコアバリューに反する（ADR-0013） |
| モデルをアプリに同梱する | large-v3-turbo だけで約 1.6 GB になり、PRD の 300 MB 以下という目標を満たせない |
| Apple Silicon でも small を既定にする | 処理は速いが、会議の専門用語の精度が落ちる。large-v3-turbo を標準とする PRD に反する |
| CPU だけで処理する | Metal を使わないと、60 分の音声を 10 分以内に処理する目標に届かない可能性が高い |

## 結果

- large-v3-turbo のダウンロードに約 1.6 GB の通信とディスクが必要になる。
  初回起動時に large-v3-turbo の約 1.6 GB のダウンロードを案内するため、通信量と空き容量の表示が必要になる。
- モデルをアプリの外に置くことで、アプリ本体のサイズを 300 MB 以下に保ちやすくなる。
  一方で、モデルが無い状態では文字起こしができないため、設定画面と初回起動時の導線を用意する必要がある。
- Apple Silicon では Metal と Core ML により処理を高速化できる。
  Core ML の成果物はモデルごとに用意する必要があり、ビルドと配布の手順が増える。
- Intel Mac は動作保証外とする。
  Apple Silicon では large-v3-turbo を既定にし、60 分の音声を 10 分以内に処理する目標を維持する。
- 言語の自動判定は、短い発話や雑音の多い会議で誤判定する可能性がある。
  日本語のヒントと用語集で補い、誤判定が続く場合は会議ごとの言語指定を次フェーズで検討する。
- 日本語と英語が混在する会議では、ファイル単位の言語判定の結果に引っ張られる。
  T-7 の完全対応には、VAD で区間を分けて言語を判定する処理が必要になる。
- 用語集を initial prompt に渡すと、専門用語の表記が安定する一方で、関係のない単語を誘導する可能性がある。
  用語集の量と内容を調整できる UI が必要になる。
- モデルを差し替えると文字起こしの品質と速度が変わる。
  `meta.json` に使用したモデル名と whisper.cpp の版を記録し、再現できるようにする。
- モデルのチェックサムを照合しないと、壊れたファイルや差し替えられたファイルを実行する可能性がある。
  ダウンロード後と起動前に検証する。
- 既存の mp3 や wav を取り込んで文字起こしする機能（PRD の T-6）は Could のため、MVP では扱わない。
  実装する場合は、録音した音声と同じ whisper.cpp の経路とモデルを使う。

## 未決事項

- モデルのダウンロード元の URL、ホスティング、SHA-256 の入手方法。
- Core ML の成果物をどのモデルについて用意するか、変換と配布の手順。
  `.mlmodelc` のサイズとチェックサムを、モデルのダウンロードのマニフェストに含めるか。
- 提供するモデルの最終的な一覧。
  small、medium、large-v3-turbo の 3 つでよいか。
- 初回起動時のダウンロードの進捗表示と、中止した場合の再開の導線。
- 用語集の保存形式、上限、会議ごとの上書き。
- whisper.cpp の `-l auto` はファイル単位の言語判定であり、日本語と英語が混在する会議の完全対応は保証できない。
  T-7 の混在言語対応を、MVP で VAD 区間ごとの判定まで含めるか、主言語の自動判定に限定するか。
  PRD の T-7 の扱いを決める必要がある。
- whisper.cpp のスレッド数、beam size、その他の推論パラメータ。
- モデルのライセンスと再配布条件の確認。
- モデルの自動更新を行うか、利用者が明示的に再ダウンロードするか。
