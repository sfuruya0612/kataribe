# ADR-0015: アプリ名とリポジトリ名を Kataribe にする

Created: 2026-10-28
Model: DeepSeek V4.1 Flash 1017
Status: Accepted

## 背景

PRD は、プロジェクト名を **Kataribe（語り部）** とし、ファンタジー RPG のジョブや役柄の名前でツールの動作を表す命名規則に揃えている。
語り部は、その場で聞いた出来事を記憶し、後の人に語り継ぐ役であり、録音、文字起こし、要約の 3 工程と役割が一致する。
主ユーザーは日本語話者で、「語り部」から用途が伝わる。
`kataribe` は打ちやすく、`Kataribe.app` と `~/Documents/Kataribe/` のパスにも収まりが良い。

一方で、アクセスログ解析ツールの `kataribe`（Go 製）と、オーディオブック生成アプリの「Kataribe: Audiobook.AI」が同名で存在する。
当初は衝突を避けるため、GitHub のリポジトリ名に用途を添える案もあった。
利用者との決定で、アプリ名とリポジトリ名を一致させることを優先する。

## 決定

- アプリの名前は `Kataribe` とする。
  アプリのバンドル名は `Kataribe.app` とする。
- GitHub のリポジトリ名は `kataribe` とする。
  アプリ名の `Kataribe` と同じ名前にし、リポジトリの表示名も `Kataribe` とする。
- 配布物の説明とストアの表示では、アプリ名に用途を併記する。
  表示名は次のとおりとする。

  | 項目 | 値 |
  | --- | --- |
  | `CFBundleName` | `Kataribe` |
  | `CFBundleDisplayName` | `Kataribe 会議録` |
  | DMG のボリューム名 | `Kataribe 会議録` |
  | About 画面 | `Kataribe 会議録` |
  | GitHub のリポジトリ | `kataribe` |
  | 既定の保存先 | `~/Documents/Kataribe/` |

  PRD の表示名ではアプリ名と用途をダッシュで区切っているが、この ADR では日本語の見出しでダッシュを使わないため、空白に変えた。
- 会議データの既定の保存先は `~/Documents/Kataribe/` とする。
  既に同名のフォルダがある場合は、そのフォルダを保存先として使い、内容を上書きしない。
- アプリ内の表記と `meta.json` のアプリ名は `Kataribe` に統一する。
  About 画面の表示名は `Kataribe 会議録` とする。
  リポジトリ名とアプリ名を一致させる理由と、同名のツールとの区別の方法を、README と配布ページに書く。
- 検索用の説明には「Kataribe 会議録」「Kataribe 文字起こし」「Kataribe 議事録」を含める。
  同名のツールと区別できるよう、会議の録音と文字起こしの用途を必ず添える。
- アプリの bundle identifier、配布用のドメイン、商標の確認は未決事項とする。
  これらは署名と配布に必要になるため、リリース前に確定する。

## 検討した選択肢

| 選択肢 | 採用しない理由 |
| --- | --- |
| `Scribe` | 文字起こしの意味は伝わるが、同種のツールと名前が衝突しやすい。一般的な英単語でもある |
| `Chronicler` | 記録する役割は伝わるが、長く、検索で他のアプリと混ざりやすい |
| `Bard` | 語り部に近いが、音楽や音声合成のツールと衝突する。Electron の構成図の名前としても使われている |
| `Oracle` | 予測やデータベースの製品名として広く使われており、会議の録音アプリの名前としては誤解を招く |
| GitHub のリポジトリ名を `kataribe-app` にする | アプリ名と一致させたいという決定に反する。検索での区別は配布名の併記で補う |
| 配布名を `Kataribe` だけにする | 同名のアプリが複数あり、利用者が用途を判別しにくい |
| 既存のツールと衝突しない別の名前に変える | 語り部の役割と 3 工程の一致という PRD の根拠を失う。配布名の併記で衝突を避ける |

## 結果

- アプリ名とリポジトリ名が同じため、利用者と開発者の間で名前の対応を説明する必要がない。
  同名のツールとの区別は、配布名の併記と説明で行う。
- 検索では同名のツールが上位に出る可能性がある。
  「会議録」「文字起こし」を併記することで、用途での検索を拾いやすくする。
- `~/Documents/Kataribe/` は他のアプリや利用者のフォルダと衝突する可能性がある。
  既存のフォルダを上書きしないことと、保存先を設定で変更できることを明示する。
- bundle identifier が未決のため、署名と公証の設定を確定できない。
  bundle identifier と Team ID は、最初の署名ビルドの前に逆 DNS 形式で決める。
  変更すると、マイクの許可と、safeStorage の Keychain の項目がリセットされるため、リリース後の変更は避ける。
- 商標の確認をしないまま配布すると、同名のアプリとの問題が起きる可能性がある。
  配布の前に、主要なストアと商標のデータベースを確認する。
- アプリ名を変更する場合は、保存先のフォルダ名、`meta.json`、bundle identifier、既存の利用者のデータの移行を合わせて考える必要がある。
- 配布名に用途を併記することで、アプリ名だけを見たときの説明は長くなる。
  About 画面と初回起動時の説明で、用途を短く伝える。

## 未決事項

- アプリの bundle identifier と Team ID。
- 配布用のドメインと、GitHub のリポジトリの公開範囲。
- 「Kataribe」の商標と、同名のアプリとの権利関係の確認。
- Mac App Store や他のストアに出す場合の表示名。
- アプリ名を変更する場合のデータ移行の方法。
- 日本語以外の言語での表示名と説明。
