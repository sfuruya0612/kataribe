PATTERN 08 / REALISM LADDER

絵札 × 横顔5 levels of realism

07 の B (顔のクローズアップ) と H (縦長の絵札と朱印) を合成し、同じ構図のまま描き込みの量だけを 5 段階に変える。右へ行くほどリアルになり、小さいサイズでは潰れていく。各段は 200 / 64 / 32 / 16 px で並べる。

  • 構図: B 寄り + H 絵札
  • 地 #5856D6
  • 髪 #1C1B4B
  • 朱 #D7261E

L1 記号 採用

32 px まで崩れない
  • 円と三角だけの横顔。肌は地と同じ藍紫
  • 髪と髷は円 2 つ。口は点 1 つ
  • 色数 4。07 の B と H をそのまま足した形

L2 図案

32 px まで崩れない
  • 額・鼻・唇・顎を実在の骨格で描いた輪郭
  • 肌色を導入。髷と簪 (金に朱の玉)
  • 伏し目の線、朱の唇、半衿と衿の 2 層

L3 線画イラスト

64 px から細部が落ちる
  • 眉、まつ毛、耳、鼻孔、頬紅
  • 髪筋 3 本。半衿の下に朱の重ね衿
  • 着物に白の鮫小紋。朱印に白の内枠

L4 陰影

128 px 以上向け
  • 肌に放射グラデーション、顎下に影
  • 髪に艶のハイライト。唇にグラデーション
  • 着物に麻の葉文様と袖の折れ影。札を金地にし雲を敷く

L5 写実寄り

About 画面向け
  • 輪郭にリムライト、二重の線、まつ毛 3 本、唇の艶
  • 髪筋 7 本と鬢の照り。簪に玉 2 つ
  • 友禅の花 3 輪、衿に金の縁。金屏風に雲と砂子
決定

L1 記号を採用する。円と三角と絵札だけの 4 色で、16 px から 1024 px まで同一の図形で済む。メニューバーの単色テンプレートも札から人物を抜くだけで形が揃う。L2 以上は描き込みを足す方向の参照として残し、About 画面のキービジュアルが必要になった時に L4 または L5 を使う。

段階の判断基準
  • L1 から L5 まで構図・配色・朱印の位置は固定。変わるのは線と面の数だけ
  • 各段で加えた要素は、ひとつ下の段に戻せば必ず消える (積み上げ式)
  • 16 px の列は、メニューバー用の単色テンプレートではなく縮小表示。実際のメニューバー用は 06 の単色版を使う
