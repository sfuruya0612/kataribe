和装の語り手8 compositions

横を向いて語る和装の人物を、同じ配色のまま構図だけ変えて並べる。A は 06 の現行案。各案を 160 / 64 / 32 px で並べ、Dock とメニューバー横での判読性を比べる。

  • 地 #5856D6
  • 人物 #FFFFFF
  • 髪 #1C1B4B
  • スクワークル 22.4%

A 現行

右向きの上半身。衿合わせ 1 本と声のアーク 3 本。06 に載せたもの。

B 寄り

顔を大きく、肩で切る。口元の点で「喋っている」を足す。32 px でも髪と顔が割れる。

C 引き (正座)

座布団に正座して語る全身。講談・落語の語り手の型。情報量が多いぶん 32 px では細部が潰れる。

D 吹き出し

白い吹き出しの中に藍紫の人物。「発話を記録する」機能がひと目で伝わる。会話アプリ全般に見える懸念あり。

E 括弧

「 」の間に語り手。引用・発言の記号で「語り」を補強する。括弧が強いので人物は小さめ。

F 月背景

淡い月を背に、人物は紺のシルエット。夜話・怪談の情緒。濃淡 3 段で 32 px でも形が残る。

G 二人

語る側 (白) と聞く側 (薄紫) が向かい合う。会議 = 対話を表す。32 px では 2 体が団子になる。

H 絵札

縦長の札 (百人一首の絵札) に語り手と朱印。白地が面積を取るので Dock で明るく見える。
